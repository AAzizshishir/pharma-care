# Project Name

PharmaCare

A scalable backend application PharmaCare is built with **Express.js**, **PostgreSQL**, and **Prisma ORM**.  
The codebase follows a **modular architecture pattern** for maintainability and clarity.

## ⚙️ Tech Stack

- **Express.js** – Web framework
- **PostgreSQL** – Relational database
- **Prisma** – Type-safe ORM
- **TypeScript** – Strong typing and maintainability
- **Modular Pattern** – Separation of concerns for scalability
